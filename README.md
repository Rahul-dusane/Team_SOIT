# HireLens

HireLens is a React + Vite recruiter workspace for multi-agent resume screening and job matching.

The frontend uses JavaScript, React Router, Axios, Tailwind CSS, Lucide React, and Recharts.

## Getting started

```bash
npm install
npm run dev
```

Open the local Vite URL to explore the dashboard, resume upload flow, job builder, candidate ranking, match detail, and comparison views. Create a production build with `npm run build`.
